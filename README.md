# Viggu Audio

A personal Android audio player built with Flutter. Audio-only scope for this first build.

## Features planned
- Local audio import and playback
- Home, Library, Now Playing, and Settings screens
- Dark, light, and system theme
- Seasonal gradient palettes
- Recently played and resume playback
- Round floating resume button
- Android headset and background playback support (follow-up build)

## Build APK
This repository includes a GitHub Actions workflow. Open **Actions**, select **Build Viggu Audio APK**, and run the workflow. Download the `viggu-audio-debug-apk` artifact from the successful run, extract it, then install `app-debug.apk` on your Android phone.

## Status
Starter UI/build setup. A successful APK build and real-device playback test are still required before treating this as a working release.
